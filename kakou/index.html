kakou — ハエ脳に回路を足す 実在のショウジョウバエのコネクトーム（FlyWire v783、13.8 万ニューロン）で動く脳に、自分で設計した回路を足すためのライブラリ。 作業記憶・AND ゲート・状態機械・新しい感覚入力が、元の挙動を 1 スパイクも変えずに入ります。

できることは 2 つです。
1. 777 KB で学習する最小の AI として使う。
2. その脳に、脳が持っていない機能を回路として足す。

1. 最小 AI として

ハエの記憶中枢（キノコ体）だけを切り出した一式が、そのまま学習器です。

普通の機械学習と違うところ

  • 誤差逆伝播がない。 規則は局所的で、「そのシナプスの入力側が最近発火した」×「その区画にドーパミンが来た」の一致だけで重みが動きます。勾配も最適化器も不要。
  • オンラインで 1 枚ずつ。 バッチもエポックもありません。先に答えさせ、間違えたときだけ、絵がまだ出ているうちに教える。
  • 学習が wasm の中で完結。 外で計算するのは最後の比較だけ。
  • 重みを持ち運べる。 exportGains() / importGains() で 133 KB のファイルにして別の個体へ。

同じ課題なら小さな CNN のほうが少ないパラメータで高精度が出ます。ここの取り柄は精度ではなく、 局所規則だけで・オンラインで・777 KB の中で完結し、その土台を回路として拡張できることです。

使う

import { FlyBrain } from 'https://hae.satoru.net/flybrain/flybrain.js';

const brain = await FlyBrain.load({ graph: '.../data/mb783.fbg.gz' });

// 何を学習させるか：入力の集団、出力の区画（クラスごとに1つ）
brain.setPlasticity({
  pre: kenyonCells,
  groups: labels.map((_, i) => ({ post: mbonsOf(i), modulators: [] })),
  eta: 6e-5, tauTrace: 40, gainMin: 0.05, gainMax: 2,
});

// 1枚見せる
for (let i = 0; i < pixels.length; i++)
  if (img[i] > 0.05) brain.stimulate(channel[i], 270 * img[i], { byIndex: true });
brain.reset(seed);
brain.run(400);

// 答え＝いちばん駆動が小さい区画
const drive = brain.driveByGroup(kenyonCells, spikeCounts);
const answer = drive.indexOf(Math.min(...drive));

// 間違えたときだけ教える（絵は出したまま）
if (answer !== truth) {
  brain.dopamine(truth, 1);       // 正解の区画を弱める
  brain.dopamine(answer, -1);     // 選んでしまった区画を強める
  brain.run(300);
}

2. 回路を足す

ハエの脳が持っていない機能を、設計して挿せます。進化と違って既存の結合を奪う必要はありません （graft.mjs がグラフ自体を拡張し、新しく送り先ができた行にだけ空きスロットを足します）。

足しても元の脳は変わりません。 以下のどの回路を入れても、砂糖・苦味・無刺激での挙動は 138,639 細胞すべてでスパイク単位一致、運動ニューロン MN9 も 78 対 78 で同じ。 新しい回路は、それが働く場面でだけ動きます。

API は 5 つだけ

import { Workshop } from './kakou/graft.mjs';

const W = await Workshop.open({ cells: 200 });   // 新しいニューロンを確保
const state = W.cells(32);                       // 使う分だけ取り出す
W.wire(from, to, 12);                            // 集団→集団（負の値で抑制性）
W.link(pre, post, 12);                           // 1本だけ
const brain = await W.build();                   // 全部入りの FlyBrain

部品カタログ

動くことを実測した部品です。数値はそのまま使えます。

記憶

素のハエ脳は、刺激が消えて 50 ms で全脳が沈黙し、何だったかを失います。保持の仕組みがありません。足します。

const seen = W.memory();        // 32細胞。書かれたら保持しつづける
seen.write(sugarCells);         // これで書き込まれ
seen.clear(bitterCells);        // これで消える

W.wire(seen, gate, 8);          // ただの細胞の配列なので、そのまま繋げる
書込（砂糖 200 ms）1,040 スパイク
保持（5 秒）17,056減衰なし。1 細胞あたり約 108 Hz
消去（苦味 200 ms）16 → 0
そのまま 2 秒0戻ってこない
再書込1,088
また保持（5 秒）17,024満額

W.memory(n, { groups, rec, write, clear }) で細かく変えられます。既定は 32 細胞・2 群・1 対 16 シナプス。 中身は輪です——全結合にすると、どんなに強くしても 25 ms しか保ちません。全員が同時に発火すると、 送り合った入力が全員の不応期に当たって捨てられ、輪が自分で自分を消すためです。groups: 1 は弾かれます。

AND ゲート（2 つ揃ったときだけ通す）

閾値下の興奮を 2 つ足す方法は使えません。最弱の 2 シナプスでも、 約 200 Hz の入力を時定数 20 ms で積分すれば閾値を超えます。強く駆動された細胞には抑制も効きません（不応期で捨てられる）。 脱抑制で作ります。

const gate = W.cells(16), veto = W.cells(8);
W.wire(signal, gate, 8);        // 信号は弱く門へ
W.wire(signal, veto, 60);       // 同時に拒否権を立てる
W.wire(veto, gate, -128);       // 拒否権は門を閉じる
W.wire(state, veto, -128);      // 状態が立っているときだけ拒否権が黙る
W.wire(gate, [mn9], 200);       // 門が開けば運動ニューロンへ

条件成立時 18.0 スパイク、不成立時 0.0。記憶と組み合わせれば 10 秒前に見たものに基づいて行動する——素のハエ脳は 0.0 対 0.0 で区別できません。

状態機械（順序を扱う）

上の 3 つを並べるだけです。A → B → C の順に来たときだけ発火する機械：

for (let k = 0; k < 3; k++) {
  const gate = W.cells(16), veto = W.cells(8);
  W.wire(input[k], gate, 8);        // AND：この入力 かつ この状態
  W.wire(input[k], veto, 60);
  W.wire(veto, gate, -128);
  W.wire(S[k], veto, -128);
  W.wire(gate, S[k + 1], 60);       // 次の状態を書き
  W.wire(gate, S[k], -32);          // 自分の状態を消す
}

20 列を試して 20 列とも正解（ABC は発火、ACB・BAC・AAB・AAA などは沈黙）。 常にちょうど 1 つの状態だけが立ちます。新規 200 細胞・7,648 接続。 順序はハエの脳に存在しない概念です。

新しい感覚入力を学習装置に繋ぐ

ハエの目はコネクトームに丸ごと入っていますが（片眼 668 個眼）、このモデルではキノコ体に 1 本も届いていません。 架けられます。

for (const ommatidium of eyes) {                  // R7 が個眼そのもの（両眼 1,336 個）
  const targets = pickRandom(kenyonCells, 71);    // 実物の投射ニューロンと同じ形
  for (const kc of targets) W.link(ommatidium, kc, 12);
}

8 場面を 0.875〜1.000 で識別（橋なしでは 0.125＝偶然）。 キノコ体の発火率は 5.4%＝本物のハエの疎符号のまま。retina.mjs が画像を個眼の発火率に変換します （個眼間角 4.77°、実物は約 5°）。

容量を増やす

const kc = W.cells(15531);                        // 新しいキノコ体細胞
for (const k of kc) {
  for (const c of pickRandom(channels, 6)) W.link(c, k, 12);   // 入力
  for (const a of APL) { W.link(a, k, -19); W.link(k, a, 22); } // 疎性の帰還ループへ
  for (const m of pickRandom(MBONs, 12)) W.link(k, m, 4);       // 読み出しへ
}

入力チャンネルを 302 → 1,602 に広げると符号の発火率が 57.7% まで上がりますが、 キノコ体細胞を 20,708 個まで増やすと 5.3% に戻ります—— 1 時間前に存在しなかった細胞に対して、既存の APL 帰還ループが正しく働きます。

組み立て例：最小の会話

部品を組むと、2 匹のハエが会話します。新しい機構はひとつも要りません。
→ ブラウザで動くデモ：会話するハエ（3D の 2 匹、経路を 1 本ずつ遮って偶然でないことを確かめられます）

デモが読むのは全脳ではなく、その会話で実際に発火する 3,150 ニューロン（1,510 万結合のうち 195,599 本）だけを切り出したものです。 発火しないニューロンを消すのは黙らせるのと等価なので、72 試行すべてが全脳とスパイク単位で一致します。 28.5 MB・107.6 MB → 281 KB・4.1 MB。kakou/cut.mjs。

// A（問う側）
const wants = W.memory();                 // 欲しい、を保持する
wants.write(driveCells);
W.wire(wants, WING, 12);                  // 欲しい＝翅を鳴らして問う
andGate(W, earYes, wants, [MN9]);         // 「はい」を聞いた かつ まだ欲しい → 食べる

// B（答える側）
const knows = W.memory();                 // 餌を見た、を保持する
knows.write(sawFoodCells);
andGate(W, earAsk, knows, CLICK, 400);    // 問いを聞いた かつ 知っている → クリックで答える

あとは 5 ms ごとに、互いの運動ニューロンが出した分を相手の聴覚に流し込むだけです。

5 シードの平均、どのシードでも同じ。※ B が何も知らない行で 77 回鳴っているのは、巨大線維（逃避のニューロン）が A の羽音に驚いているだけです。本物のハエもそうします。本当の返事の 1/3 の頻度で、A の門を開く水準には届かないので誤答にはなりません。

どちらの側も素のハエにはできません。 B は「餌を見た」を 50 ms しか保持できず、 どちらも「聞いた信号」と「自分が知っていること」を突き合わせる手段を持っていません。 A の欲求と B の知識に砂糖を使わなかったのは、砂糖が単独で MN9 を 63.8 Hz で駆動してしまい、 会話が起きる前に結果が決まるからです（LC4 と LC11 はどちらも 0.0 Hz）。

知っておくべき制限

  1. 同期させない。 不応期のニューロンに届いた入力は——興奮も抑制も——破棄されます。 全結合の自己興奮は自滅し、飽和した細胞には抑制が効きません。輪と脱抑制で構造的に回避してください。強度の調整では解決しません。
  2. 入口と容量は一組。 302 チャンネル × 71 細胞 = 21,442 接点。チャンネルだけ 1 万本にすると 1 本が 2.1 細胞にしか届かず、存在しないのと同じになります。必ず一緒に増やす。
  3. 嗅覚経路に位置情報は入りません。 画素はシャッフルして配られるので置換不変で、 局所特徴という概念が原理的に存在しません。位置が要るなら目から入れてください。
  4. この模型では目が伝わりません。 光受容器は撃つのに中枢へ 0 スパイク。配線は在る（2,572 細胞が閾値分を受けている）が、 実際のハエの光受容器がスパイクを出さない段階的電位の細胞なので、LIF モデルに載りません。上の「橋」で迂回します。
  5. キノコ体だけ使うときは外を黙らせる。 全脳モデルは嗅覚入力で暴走します（詳細）。 brain.silence(outside, true) を忘れると測定が 3 倍狂います。

まだ示していないこと

ここに並んでいるのは機構の実測です——回路が何をするか、動物に何を払わせるか。 どの回路も「学習課題の点数を上げる」ことはまだ示していません。 入口を広げた脳の学習実験は、基準条件（3,000 回練習で未知書体 0.5087）だけ完走して、残りは途中です。
