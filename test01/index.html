ハエの脳に砂糖の味を入れたら、口は動くか

ショウジョウバエの脳の配線図（コネクトーム）をそのままコンピュータ上で動かす philshiu/Drosophila_brain_model （Shiu et al., Nature 2024）を、このサーバーで再実行しました。 右側の口にある「甘さを感じる神経」21個だけを刺激して、脳の中を信号がどう広がり、 口吻（ハエの口）を伸ばす運動ニューロン MN9 まで届くかを見ます。

データを読み込み中…

1. 信号が脳を伝わっていく様子

1試行（1秒間）のスパイク（神経の発火）を1本ずつ点で表示。縦は発火の多かったニューロン上位160個で、 甘味神経から何段のシナプスを経て届くか（段数）でまとめています。点にカーソルを合わせると名前と発火率が出ます。

2. 段ごとの発火の立ち上がり

30試行を平均した、段ごとの合計スパイク数（10ミリ秒ごと）。刺激した神経（0段）が発火を始め、 数ミリ秒遅れて次の段が続きます。

3. どのニューロンがよく発火したか

30試行平均の発火率 上位25個。細い線は試行間のばらつき（標準偏差）。 名前は論文で同定された細胞タイプ、空欄は未命名のニューロン（FlyWire ID の末尾を表示）。

    注意点

    • このモデルは「全ニューロンが同じ性質の単純な神経（LIF）」「シナプスの強さは本数に比例」という大胆な単純化をしています。それでも砂糖→口吻伸展のような行動に対応する経路が配線だけから出てくる、というのが論文の主張です。
    • 刺激はポアソン入力（ランダムなタイミング）なので、試行ごと・実行ごとに結果は少しずつ揺れます。
    • サーバーに Python の開発ヘッダがないため Brian2 は低速な numpy モードで動かしました。計算結果は同じで、速度だけが違います。
    • 「段数」は興奮性シナプスだけをたどった最短経路です。実際の信号は抑制性の経路や複数経路の合流の影響も受けます。
